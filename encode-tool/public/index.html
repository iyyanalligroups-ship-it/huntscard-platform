Test a card

Place any card on the reader to see the URL stored on it, whether it's password-protected, and a mobile preview of the page -- all from one tap, right here on localhost. This never touches the database.

Password tester

Enter the exact chip password (shown once, when a card was encoded) and tap the card. This attempts a real authentication -- not a guess -- so it will tell you clearly whether THIS password genuinely unlocks THIS card.

Rewrite test

The real-world test: actually attempt to write new data to the card. If it's genuinely protected, this must fail without the correct password. This never touches the card's real profile URL -- it writes to a separate, unused test area.

Recover a card

For a card that was written with the wrong data and is already password-locked. Enter its exact chip password below, then tap the card. This authenticates with that password, wipes the card's data back to blank, and removes the password lock entirely -- afterward the card behaves like a brand-new one and can go through Write or Create a card again from scratch.

This is destructive and can't be undone: the old data and old password are both gone the moment this succeeds. Only use this on the specific card the password below belongs to.

Blank a card with no password

For a card that is NOT password-protected (never locked, or a lock attempt failed before it took effect) but still has old data on it. Tap the card below -- this wipes its data back to blank with no password needed. Afterward it behaves like a brand-new card and can go through Write or Create a card again from scratch.

This is destructive and can't be undone. Only use this on a card you've confirmed (e.g. via Read mode) is genuinely unprotected -- if it's actually password-locked, use "Unlock & wipe this card" above instead.

Card type analyser

Tap any card to see its real chip type before writing to it. This tool's password lock only works on NTAG216 cards (231 pages) -- some cards sold/labeled as NTAG216 have turned out to actually be NTAG213 (45 pages), which will write and verify fine but fail when it's time to set the password lock. Check a new batch of blank cards here first to catch that up front.
